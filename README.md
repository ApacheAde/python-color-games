# Python Color Games

A small collection of **original**, full-color Python 3 games built with [pygame](https://www.pygame.org/).

These are simple arcade / table games — **not** commercial emulators and **not** Nintendo, Vegas, or casino-brand clones.

Featured on / shout-out: [x.com/ElbowOS](https://x.com/ElbowOS)

## Games

| File | Genre | Controls |
|---|---|---|
| `pipe_jumper.py` | Platformer (Mario-style *feel*, original art) | ← → move, Space jump, R restart |
| `neon_blackjack.py` | Card game | H hit, S stand, N new hand |
| `lucky_reels.py` | Casino slots | Space spin |
| `color_wheel.py` | Casino roulette | 1–3 bet color, Space spin |
| `memory_flip.py` | Card matching | Click two cards |

## Run

```bash
uv sync
uv run main.py
```

Needs Python 3.10+ and a windowed desktop (pygame).
